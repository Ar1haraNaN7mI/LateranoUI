# Source provenance

LateranoUI is extracted from the Laterano presentation in
[deepseek-harness-rust-optimize](https://github.com/Ar1haraNaN7mI/deepseek-harness-rust-optimize),
commit [`16dbd2d8473bb956f27f1d87c709cddeacbf2881`](https://github.com/Ar1haraNaN7mI/deepseek-harness-rust-optimize/commit/16dbd2d8473bb956f27f1d87c709cddeacbf2881).

The export contains the HTML/Canvas/SVG presentation, its shared text, audio,
identity and embed client, and an independently named optional adapter for the
official DeepSeek Harness web host. It uses Laterano as its only visual style,
including when an older host returns a different saved preference.

The source Rust engine, TUI, Windows application, profile database, credentials,
personal settings, and Rhine renderer are not included. The original project
continues to provide both selectable themes and all three Rust clients.

The bundled preview images document the original implementation; they are not
inventories or loaded results from a visitor's computer. Refer to
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for individual asset provenance
and to the voice manifest for generated audio details.
